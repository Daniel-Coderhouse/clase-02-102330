JSX
JS extension

Para devolver mas de un elemento jsx, debo usar un div o bien un fragment <></>
Para interpolar codigo de js en el jsx debo usar {}
Si yo necesito en el jsx utilizar un bloque if, un for, recorrer un array con un map,
o hacer cualquier operacin de js, debo hacerlo entre llaves {}

Para styling usamos la palabra reservada className, en vez de class
